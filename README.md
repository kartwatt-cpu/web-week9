# Web 编程课程实践 · Todo 事件委托版（第 8 周）

深圳大学《Web 编程》课程作业仓库。第 8 周在 V2.0 数据驱动的基础上，把列表交互从「每条 li / 每个按钮各自绑监听器」改成**父容器 ul 上的事件委托**，并用 AI-2 五步法完成一次调试挑战。

- 仓库地址：<https://github.com/kartwatt-cpu/web-week8>
- 直接本地运行：浏览器打开 `index.html` 即可（全部资源都是相对路径，`file://` 也能跑）

## 第 8 周做了什么

- **事件委托**：整条列表只在 `ul.todo-list` 上挂一个 `click` 监听器，删除 / 切换统一交给它分流；
- **dataset 定位**：li 用 `dataset.id` 记住自己对应哪条 todo，删除按钮用 `data-action="delete"` 标记；
- **边界防御**：`e.target instanceof Element`、`closest('li')` 空值、`list.contains(item)`、无 `data-id` 四层兜底；
- **操作分流**：删除分支执行后 `return`，避免又落到 `toggleTodo` —— 这正是本周调试挑战的缺陷点。

## 验证方式

1. 浏览器打开 `index.html`，控制台确认无报错；
2. 点击任务文字 → 只切换完成状态；点击 `×` → 只删除；
3. 点击列表空白处 → 不报错；
4. 动态新增任务后直接点击 → 委托自动生效，无需重新绑定；
5. 刷新页面 → 数据与完成状态仍在。
